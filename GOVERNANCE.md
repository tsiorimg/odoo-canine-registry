# Governance

Open Canine Registry is currently maintained by [@tsiorimg](https://github.com/tsiorimg).

## Decision making

Project decisions are discussed publicly through GitHub issues and pull requests. Decisions with a long-term architectural, legal, security, or operational impact are recorded in `docs/adr/`.

While the project has one active maintainer, the maintainer is responsible for accepting changes and releases. When a second regular maintainer joins, changes to protected branches should require at least one independent approval.

## Contributions

Every change should:

1. reference a GitHub issue;
2. use a short-lived branch;
3. be proposed through a pull request;
4. include relevant tests and documentation;
5. pass all required status checks.

Maintainers may reject contributions that expose personal data, include unauthorized branding, weaken security, or fall outside the documented scope.

## Releases

Development releases use semantic versions below `1.0.0`. The first MVP suitable for a formal presentation is expected to become `1.0.0` after validation.

## Project independence

This repository is an independent open-source initiative. It is not currently endorsed, operated, or sponsored by the Association des Cynophiles de Madagascar (ACYM).
