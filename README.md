# Open Canine Registry

Open Canine Registry is an open-source canine registry platform built for **Odoo 19 Community**.

> [!IMPORTANT]
> This is an independent community project in its early design phase. It is not an official product of, and is not currently endorsed by, the Association des Cynophiles de Madagascar (ACYM).

## Goals

The project aims to provide a maintainable foundation for:

- canine owners, dogs, breeds, identifiers, and ancestry;
- mating, birth, litter, and registration workflows;
- imported-dog registration;
- evidence and document management;
- validation, correction, approval, and rejection workflows;
- payment tracking;
- pedigree PDF generation;
- portal access and privacy-aware public search.

See [the project scope](docs/project-scope.md) for the MVP boundaries.

## Current status

The project is in **M0 — Foundation and Governance**. Business features are not implemented yet.

Follow the [M0 backlog](https://github.com/tsiorimg/odoo-canine-registry/issues) to track progress.

## Technology

- Odoo 19 Community
- PostgreSQL
- Docker for local development
- GitHub Actions for continuous integration

## Contributing

Contribution instructions will be added during M0. Until then, every proposed change should reference an issue and be submitted through a pull request.

Do not commit production data, real personal records, animal documents, photographs, payment details, organizational logos, or other third-party material without explicit authorization.
